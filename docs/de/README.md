# dskripchenko/laravel-admin-oidc

> 🌐 [English](../../README.md) · [Русский](../ru/README.md) · **Deutsch** · [中文](../zh/README.md)

Anmeldung an [`dskripchenko/laravel-admin`](https://github.com/dskripchenko/laravel-admin)-Panels per OpenID Connect — Keycloak, Microsoft Entra ID, ADFS, Authentik oder jeder OIDC-Anbieter: Kontoanlage, Rollenzuordnung, eigene Anbieter je Mandant.

## Installation

```bash
composer require dskripchenko/laravel-admin-oidc
php artisan migrate
```
