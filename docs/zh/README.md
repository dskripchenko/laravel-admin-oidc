# dskripchenko/laravel-admin-oidc

> 🌐 [English](../../README.md) · [Русский](../ru/README.md) · [Deutsch](../de/README.md) · **中文**

通过 OpenID Connect 登录 [`dskripchenko/laravel-admin`](https://github.com/dskripchenko/laravel-admin) 面板——Keycloak、Microsoft Entra ID、ADFS、Authentik 或任何 OIDC 提供方：自动创建账户、角色映射、按租户配置提供方。

## 安装

```bash
composer require dskripchenko/laravel-admin-oidc
php artisan migrate
```
